== Installation ==

1. Upload the weluka folder to the plugins directory in your WordPress installation
2. Go to plugins list and activate "weluka". 
3. Upload the weluka folder to the theme directory in your WordPress installation
4. Go to themes list and activate "weluka-theme-00". 

Visit our [documentation pages](https://www.weluka.me/builder_install)
